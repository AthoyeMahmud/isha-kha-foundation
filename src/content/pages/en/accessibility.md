## Reading and navigating

The website offers English and Bangla versions. The language link in the header opens the same page in the other language. The sitemap provides a subject-based list of pages, including individual activity records.

Text can be enlarged using browser zoom. Page layouts adapt to narrow screens, and the reading pages use a limited line length. The site does not play audio or video automatically.

## Using a keyboard

A “Skip to content” link appears when focused, allowing keyboard users to bypass the header. Links have visible focus indicators. The mobile menu uses a native disclosure control that can be opened and closed with a keyboard.

Pages use headings, navigation landmarks and descriptive link text. Photographs have text descriptions and source captions. The document reading editions are available as web text and downloadable UTF-8 text files.

## Scope of the accessibility work

The design uses WCAG 2.2 AA as its accessibility target. A target is not a claim that every criterion has been independently audited. Features and content should be evaluated as the site changes.

External websites and the original photographs of text may have different accessibility limitations. Where a photographed cover is shown, the surrounding page gives the readable information used for its description.
